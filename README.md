# 算法游乐场 · Algorithm Playground

一个用原生 HTML、CSS、JavaScript 实现的算法可视化游戏站。

目前包含两个可玩模块：

- **A* 寻路实验室**：在 20 × 20 网格中绘制墙壁，观察 A* 的彩虹探索过程与最短路径回放。
- **二分拆弹**：60 秒倒计时内，从 1–100 中猜出隐藏密码；每次猜测都会让被排除的区间变灰。

打开根目录的 `index.html` 会先进入游戏大厅，也可以在任意页面左上角的「选择游戏 / 切换游戏」菜单中选择模块。

## 功能总览

### 大厅

- 双游戏卡片入口
- 左上角全站算法切换菜单
- 共享的视觉系统与响应式布局

### A* 寻路实验室

- Canvas 20 × 20 网格，支持鼠标拖拽绘制墙壁、放置起点和终点
- A* 寻路（四邻接 + 曼哈顿距离 + 最小堆）
- 彩虹探索动画：从紫色渐变到粉色
- 深色高亮最短路径与白色描边
- 寻路完成后可拖动的过程时间轴，逐帧回看探索与回溯
- 寻路步数、探索节点数与计时器
- 成功 / 失败结果弹窗、随机地图
- C++ / Java / Python / Go 四语言源码与详细解析

### 二分拆弹

- 随机密码隐藏在 1–100 的整数中
- 点击「开始拆弹」后启动 60 秒倒计时
- 输入任意有效候选数字进行猜测，实时获得「更大 / 更小」提示
- 1–100 十段式进度条实时将被排除区间变灰
- 剩余候选、已排除数量和猜测次数统计
- 正确命中即拆弹成功；时间耗尽则炸弹爆炸并揭晓密码
- 阅读源码时自动暂停倒计时，关闭后继续
- 倒计时中切换算法会先弹出警告；确认后炸弹立即爆炸，再跳转到目标页面
- C++ / Java / Python / Go 四语言源码与详细解析

## 启动方式

项目没有第三方依赖，也不需要构建。

### 最简单的方式

直接双击根目录的 `index.html`，用 Chrome、Edge 等现代浏览器打开。

### 推荐：本地静态服务器

在命令行执行：

```bash
py -m http.server 8000 --directory D:\Algorithm_Game
```

然后访问：

```text
http://localhost:8000
```

也可以使用 VS Code 的 Live Server 插件启动。

## 操作说明

### 全站

| 左上角「选择游戏 / 切换游戏」 | 打开算法切换菜单 |
| 点击「源码与解析」 | 打开对应算法的四语言源码与详细解析 |

### A* 寻路

| 操作 | 说明 |
| --- | --- |
| 拖拽左键 | 用当前工具编辑网格 |
| 右键 | 快速擦除墙壁 |

| `1` / `2` / `3` / `4` | 切换墙壁 / 起点 / 终点 / 擦除工具 |
| `R` | 生成随机地图 |
| `C` | 清空障碍物 |
| 拖动底部时间轴 | 寻路完成后回看探索与路径回溯 |

### 二分拆弹

| 操作 | 说明 |
| --- | --- |
| 点击「开始拆弹」 | 生成随机密码并启动 60 秒倒计时 |
| 输入数字后点击「确认」或按 `Enter` | 提交一次猜测 |
| 观察灰色区间 | 已被排除的数字范围 |
| 点击结果按钮 | 开启下一局 |

倒计时中打开源码解析会自动暂停计时；倒计时中切换页面会弹出警告，确认后炸弹立即爆炸，再自动切换到所选算法。

## 实现简述

### A*

1. 格子使用一维编号 `y * 20 + x`。
2. 优先队列按 `f = g + h` 排序，`h` 使用曼哈顿距离。
3. 搜索完成后沿父节点数组回溯最短路径。
4. 探索与路径动画由 `requestAnimationFrame` 驱动，时间轴通过把滑块位置映射回同一动画时间实现回放。
5. 探索节点按访问顺序在七段彩虹色板中插值，并带有缩放、淡入效果。

### 二分查找

1. 初始候选区为 `[1, 100]`。
2. 每次猜测与隐藏密码比较，将 `low` 或 `high` 向区间内部收缩。
3. 页面把 100 个候选数字渲染成 100 个细条，区间外的数字实时变灰。
4. 倒计时使用 `performance.now()` 计算剩余时间，避免 setInterval 累积误差。
5. 源码解析打开时暂停计时，切换算法确认后触发爆炸动画并延迟跳转。

## 可调整项

### A*

- `algorithms/astar/astar.js` 顶部：`RAINBOW_STOPS`、`TIMING`、`GRID_SIZE`
- `generateRandomWalls()` 中的 `wallProbability`：随机墙壁密度

### 二分拆弹

- `algorithms/binary-search/binary-search.js` 顶部：`ROUND_MS`、`LOWER_BOUND`、`UPPER_BOUND`
- `renderStats()` 可加入更多游戏统计
- `algorithms/binary-search/binary-search.css` 中的 `.range-cell` 可调整排除条颜色

### 源码内容

每种语言的实现、展示用文件名和语言要点分别位于：

- `algorithms/astar/astar-docs.js`
- `algorithms/binary-search/binary-search-docs.js`

每种语言的详细解析 HTML 模板分别位于对应页面的 `<template>` 元素中。

## 兼容性

已在 Chrome 中实测桌面与移动端布局，支持直接通过 `file://` 打开；使用本地静态服务器运行体验更稳定。
