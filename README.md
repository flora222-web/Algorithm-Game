# 算法游乐场 · Algorithm Playground

一个用原生 HTML、CSS、JavaScript 实现的算法可视化学习站。

没有构建步骤，没有第三方运行时依赖，可以直接用 `file://` 打开。当前版本是 **v1 学习闭环版**：

- **A\* 寻路实验室**：先进入 A\* 学习首页，按固定关卡练习，再进入自由探索驾驶舱。
- **二分拆弹**：用 7 根线、区间不变量和预测，理解二分查找为什么最多 7 次。
- **算法首页 / 关卡内小测**：每个算法先展示纵向入口列表；小测放在关卡内部，答对后直接进入下一关。
- **概念先导**：先让学习者做选择、看现象，再揭示术语；不是一上来就甩公式。
- **学习进度**：预测正确率、关卡掌握度、角色反转和前后测都存在本机。

## 快速开始

直接双击根目录的 `index.html`，或在命令行启动静态服务器：

```bash
py -m http.server 8000 --directory D:\algorithm-game
```

然后访问：

```text
http://localhost:8000
```

推荐 Chrome / Edge。页面也支持直接通过 `file://` 打开。

## 学习设计

页面按“先体验、后命名”组织：

1. **先遇到问题**：例如“你更相信终点估计，还是更愿意稳妥探索？”
2. **先做选择**：稳妥 / 标准 / 激进；找第一个 / 找最后一个。
3. **先看结果**：扩展节点、路径步数、第一次分歧。
4. **再揭示术语**：启发函数 `h`、启发权重 `w`、`lower_bound` / `upper_bound`、单调谓词、二分答案。
5. **最后小测**：考“为什么”，不考名词背诵。

## 页面结构

```text
/index.html                         大厅
/algorithms/astar/index.html        A* 学习首页（纵向入口）
/algorithms/astar/play.html          A* 关卡 / 自由探索驾驶舱
/algorithms/binary-search/index.html 二分学习首页（纵向入口）
/algorithms/binary-search/play.html  二分关卡 / 自由探索驾驶舱
```

学习首页按行列出关卡、自由探索和源码解析；小测不放在首页，而是在关卡完成目标后出现在关卡内部。

## 功能总览

### 大厅

- A\* 与二分两张游戏卡片，进入对应算法首页
- 全站算法切换菜单
- **3 分钟学习测评**：放大入口，说明“不是考试，不计分；前测看直觉，后测看进步”
- 共享视觉系统与响应式布局

### 算法学习首页

- 纵向入口列表，一行一个关卡 / 模式；后续加内容只需加一行
- 顶部显示已掌握数量、预测正确率、继续学习
- 关卡状态：未开始 / 待小测 / 已掌握
- “更多”入口：自由探索、源码解析；二分另有角色反转
- 关卡使用固定地图 / 固定 secret；进入后不能切关或改关卡地图
- 目标完成后在关卡内出现小测；答对后才出现“下一关”

### A\* 寻路实验室

- Canvas 20 × 20 网格，鼠标/触摸绘制墙壁、放置起点和终点
- A\* 寻路：四邻接、曼哈顿启发、最小堆
- 事件流驱动：开放集、当前节点、`g / h / f`、扩展顺序、路径回溯
- 播放 / 暂停 / 单步 / 时间轴回放
- 先预测路径步数，再运行验证；记录历史预测正确率
- 三算法对比：A\* / BFS / Dijkstra 的扩展节点、路径步数、计算耗时
- **导航风格**：稳妥 / 标准 / 激进，对应启发权重 `w = 0 / 1 / 2`
- **“为什么？”教程**：`g` / `h` / `f` → 选最小 `f` → `w` 放大 `h` → 机制小测
- **首次分歧**：标准 vs 当前风格，显示第一个不同的扩展节点、双方 `g/h/f` 与路径差
- 开放集格子显示小号 `f`；底部决策提示解释“为什么先扩展它”
- **绕路陷阱地图**：演示激进模式可能扩展更少但路径更长
- 3 个固定关卡：启发对比、平局打破、无路可达；目标自动判定，完成小测点亮掌握徽章
- 关卡模式锁定地图；自由探索才开放画布编辑、完整对比和教程
- C++ / Java / Python / Go 四语言源码与解析（从算法首页进入）

### 二分拆弹

- 隐藏密码 1–100，7 根拆弹线，60 秒倒计时
- 每次猜测给出“太大 / 太小”，实时收缩 `low / high`
- 先预测下一次 `mid`，再提交猜测；记录预测正确率
- 历史表、剩余候选、已排除区间、猜测次数
- **6 个固定关卡**：
  1. 示例演示：固定 secret = 62
  2. 7 根线：拆弹 + 最坏次数小测
  3. 区间不变量：连续 3 次写出新区间
  4. 死循环排查：`low = mid` 的 buggy 二分
  5. 重复元素：找第一个 / 最后一个，结束才揭示 `lower_bound` / `upper_bound`
  6. 最小电量：隐藏阈值的“能否撑过 8 小时”单调谓词，结束才揭示二分答案
- **角色反转 · 你当出题人**：你设 secret，电脑只用 `nextMid` 猜，你当裁判回答“太大 / 太小 / 命中”；结束后看路径决策树
- 角色反转会检测“裁判不一致”，并说明为什么二分可能找不到
- 角色反转双题小测通过后记录 `binary · oracle` 掌握度
- 关卡模式隐藏关卡切换；目标完成后在关卡内小测，答对后进入下一关
- C++ / Java / Python / Go 四语言源码与解析（从算法首页进入）

### 布局

- A\* 与二分都使用 **Layout A 驾驶舱**：顶部任务条、右侧状态/对比/关卡标签、任务详情抽屉
- 页面宽度上限 1480px，画布/炸弹区域受视口约束，尽量在 1600 × 1000 一屏内完成主要操作
- 窄屏允许纵向滚动；右栏和关卡列表内部滚动

## 实现简述

### A\*

1. 格子使用一维编号 `y * 20 + x`。
2. 优先队列按 `f = g + w · h` 排序；`h` 为曼哈顿距离，默认 `w = 1`。
3. `w = 0` 时退化为按 `g` 排序（接近 Dijkstra）；`w > 1` 为加权 A\*，不保证最短。
4. 搜索产生事件流（expand / open / path / done），UI 按事件渲染开放集、当前节点和路径。
5. 三算法对比使用同一张地图、同一对起终点；首次分歧通过比较 `visited` 序列得到。
6. 回放使用时间轴映射到事件索引，支持播放、暂停、单步和拖动。
7. `play.html?level=...` 锁定固定地图并自动判定目标；`?mode=custom` 保留完整驾驶舱；`?docs=1` 自动打开源码。

### 二分

1. 初始候选区为 `[1, 100]`；每次取 `mid = low + floor((high - low) / 2)`。
2. 猜小 `low = mid + 1`，猜大 `high = mid - 1`。
3. 重复元素关卡使用 lower_bound 写法：`a[mid] >= target` 时 `high = mid`，保留 mid 作为候选。
4. 最小电量关卡把“容量是否够”抽象成单调谓词，二分答案。
5. 角色反转只让电脑看 `low/high`，不读 secret；学习者回答不一致时显式警告。
6. `play.html?level=...` 使用固定 secret/数组/阈值；`?mode=custom` 随机，`?mode=oracle` 打开角色反转。
7. 进度和预测记录写入 `localStorage`，无后端。

## 已知边界

- 纯前端，没有账号和后端同步；进度只在当前浏览器。
- 尚未做键盘网格编辑（A\* 地图目前以鼠标/触摸为主）。
- 尚未做未知范围/指数搜索；二分仍以已知 1–100 为主。
- 学习测评是 6 道固定题，主要用于前后对比，不是标准化测验。
- 视觉和交互回归由人工在目标浏览器完成。

## 兼容性

已在 Chrome 桌面和移动视口做过无头/手动检查，支持 `file://` 直接打开；使用本地静态服务器体验更稳定。
